FAQ

أسئلة بتتكرر

معلومات أساسية عن PR MC.

إيه عنوان IP السيرفر؟

لسه ما اتحطّش عنوان رسمي. زر نسخ الـ IP حاليًا تجريبي، ضيف عنوان السيرفر الحقيقي في الكود قبل نشر الموقع.

هل الموقع متصل بسيرفر ماين كرافت فعلًا؟

دي نسخة واجهة جاهزة للتخصيص. عرض حالة السيرفر الحقيقية أو ربط التقديمات بلوحة إدارة محتاج بيانات وخدمة خلفية.

إزاي أقدّم للانضمام؟

اضغط زر «قدّم للانضمام» واملأ النموذج. النسخة الحالية تجهز رسالة يمكنك نسخها وإرسالها للإدارة؛ لا ترسل البيانات تلقائيًا لأي مكان.

أقدر أغيّر الصور والألوان؟

أيوه. الألوان متجمعة في متغيرات CSS أعلى الملف، وتقدر تبدّل التصميم والصور بسهولة.
